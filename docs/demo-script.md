# 五分钟演示脚本

目标时长：4:30–5:00。录制前先构建镜像、关闭通知、隐藏 `.env` 和任何密钥页面。

## 录制前 5 分钟

- Docker Desktop 显示 Engine running；
- `docker compose ps` 三个核心服务 healthy；
- 浏览器缩放 100%，控制台字体可读；
- 清理不相关标签页、通知、终端历史和个人账号；
- 打开 README、架构图、网页控制台和 Git 提交记录；
- 准备两个明显不同的 session 名称；
- 本版 Fake Agent 不消耗 Anthropic Key，口述时明确这一边界。

## 时间线与口述

| 时间 | 画面 | 口述重点 |

| 0:00–0:25 | 仓库 README | 任务目标：把单会话 Streamlit 演示改造成可并发的持久化控制面 |

## 建议口述结尾

“这个版本重点完成了评分最高的后端设计、实时流、并发隔离和可复现文档。演示任务使用确定性 Fake Agent，避免把网络、费用和模型随机性引入 CI；真实 Anthropic callback 已与 UI 解耦，但模型到每会话远程桌面的工具桥仍作为明确边界披露。”
