## 使用方法

1. 先阅读对应阶段的 `README.md`，了解验证范围和结果。
2. 按“复验步骤”重新执行命令。
3. 在 `materials/` 查看原始命令输出、接口数据和截图。
4. 结合记录中的 Git 分支与提交号定位对应代码。

所有时间均使用中国标准时间；接口数据中的 `Z` 时间戳为 UTC。
